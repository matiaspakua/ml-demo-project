MobileNet Architecture: V2 vs V3

Both are efficient CNN architectures designed for mobile/edge devices. Here's how they compare.

MobileNetV2 V2

Parameters3.5 million
Top-1 Accuracy71.8%
Inference SpeedFaster
Key InnovationInverted Residuals + Linear Bottlenecks
Introduces bottleneck residual blocks (inverted residuals) where the input and output are thin, while the expansion happens inside the block. Uses ReLU6 activations and depthwise separable convolutions to keep the model lightweight. The linear bottleneck avoids information loss from non-linearities in narrow layers.

MobileNetV3 Large V3NEW

Parameters5.4 million
Top-1 Accuracy75.8%
Inference SpeedSlightly slower
Key InnovationNAS + NetAdapt + Squeeze-and-Excite
Built on V2's inverted residuals but improved with Neural Architecture Search (NAS) and NetAdapt for optimal layer design. Adds Squeeze-and-Excite (SE) attention modules that adaptively recalibrate channel-wise feature responses. Uses hard-swish activation and a redesigned h-sigmoid for the SE gating function.
Bottleneck residual block architecture shared by V2 and V3. V3 adds Squeeze-and-Excite (SE) attention between the depthwise and pointwise convolutions, plus uses hard-swish activation and NAS-optimized channel counts.
